# wabi_sabi

Flutter components for the wabi-sabi design system. The colours, spacing, type and
motion come from the same DTCG tokens as the React library, `@wabi-sabi/ui`, so the two
platforms cannot drift apart.

## Use

```dart
import 'package:wabi_sabi/wabi_sabi.dart';

MaterialApp(
  theme: WabiTheme.light(),
  darkTheme: WabiTheme.dark(),
  home: Scaffold(
    body: WabiCard(
      title: 'Free plan',
      footer: WabiButton(onPressed: upgrade, child: const Text('Upgrade')),
      child: const Text('Three projects and one member.'),
    ),
  ),
);
```

Components read their colours with `context.wabiColors`, from the `WabiColors` theme
extension. They never use a colour constant, so a theme switch restyles them.

## Components

| Component | React counterpart | Notes |
| --- | --- | --- |
| `WabiButton` | `Button` | `onPressed: null` disables it, the Flutter convention. |
| `WabiTextField` | `TextField` | `controller` + `onChanged` for the value, `enabled: false` to disable. |
| `WabiCard` | `Card` | The title is marked as a header for assistive technology. |

### Known limitations

- `WabiButton` loses keyboard focus while `loading`. Material does not keep a disabled
  button focusable; the React Button does stay focusable.
- `WabiButton` shows focus with a 2px border inside the button, not an offset outline as
  on the web.

## Tokens

Everything under `lib/src/tokens/` is generated by `build-tokens` from `/tokens` at the
repository root. Edit the JSON and run `pnpm tokens`; never edit the Dart files.

## Development

```bash
flutter pub get        # from the repository root: it is a pub workspace
flutter analyze
flutter test           # widget tests and accessibility guidelines, both themes
```
